- **Teams join automation avoids unnecessary waits.** Pre-join readiness now handles the browser-choice screen without a separate ten-second wait, optional controls are checked when visible, and AV confirmation handling can recover from a blocked Join click promptly. Live join latency still depends on browser startup, Teams loading, and host admission; a five-second end-to-end target remains to be measured.
- **Bot startup follows display/audio readiness.** Ready devices proceed without a fixed one-second audio sleep. Teams media warm-up requests microphone audio without requiring a camera; a missing microphone still follows the existing no-media confirmation path. Live Teams initialization and admission still determine end-to-end join time.
- **Scheduled joins use Settings-configured transcription.** Calendar auto-join delegates backend validation to the same spawn path as manual joins, so a configured backend in Settings can start a scheduled bot without duplicate environment configuration. Missing configuration still blocks the spawn and records the error with retry backoff.
